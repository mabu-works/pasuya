# ぱすや｜パスワード生成

暗号学的に安全な乱数を使ってパスワードを生成する、静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

| バージョン | 1.0.0 |
| 状態 | 公開中 |
| 稼働先 | [pasuya.vercel.app](https://pasuya.vercel.app) |
| 実装 | HTML / CSS / JavaScript（素の、外部リソース不使用）＋ Windows 版（.NET 8 / WinForms） |
| 更新履歴 | [CHANGELOG.md](CHANGELOG.md) |

## 📖 概要

**生成したパスワードはどこにも保存・送信されません。履歴も残しません。** すべての処理は利用者の端末のブラウザ内だけで行われます。

## ✨ 機能

- 長さの指定：スライダーと数値入力（8〜64文字、連動表示）
- 文字種の選択（トグル）：
  - 小文字 `abc…z`
  - 大文字 `ABC…Z`
  - 数字 `012…9`
  - 記号 `!@#$%^&*()-_=+[]{}|;:,.<>?/`
- 選択した各文字種から最低1文字ずつ含める生成（長さが文字種の数以上の場合。長さ最小8・文字種最大4のため通常は常に対象）
- 紛らわしい文字の除外オプション
  - 除外対象は次の6文字です：`0`（ゼロ）、`O`（大文字オー）、`1`（いち）、`l`（小文字エル）、`I`（大文字アイ）、`|`（縦線）
- 複数候補の一括生成（1 / 3 / 5 / 10個、初期値は5個）
- エントロピー表示：`長さ × log₂（文字プールの大きさ）`（ビット、小数点以下切り捨て）と強さの目安
- 候補ごとのコピーボタン＋コピー完了フィードバック（失敗時は手動コピー用に選択状態へ）
- 文字種が未選択の場合はエラーを表示して生成しません
- ページ読み込み時と、設定変更時・「生成する」ボタン押下時に自動で再生成します
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- テーマ切り替え（ダーク／ライト。選択は端末内にのみ保存され、初期表示はダーク）

## 📝 使い方

1. 長さをスライダーまたは数値で指定します。
2. 使いたい文字種にチェックを入れます。読み間違えやすい文字を避けたい場合は「紛らわしい文字を除外する」を有効にします。
3. 生成結果から使いたいパスワードを選び、「コピー」でクリップボードにコピーします。別の候補が欲しい場合は「生成する」を押します。
4. ページを閉じる・再読み込みすると表示中のパスワードは消えます（保存されていないため復元できません）。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。Web 版と同じ文字セット・生成方式（各文字種から最低1文字、暗号学的な乱数）で、オフラインで使えます。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Pasuya.exe` を生成（GitHub Release にはバイナリを添付しない方針のため、配布はビルド成果物で行います）
- 乱数は .NET の RandomNumberGenerator を使用。生成したパスワードは保存されません
- Web 版との差分：生成個数に20個の選択肢がある、エントロピー表示が概数（約 〜 bit）である、など表示まわりの軽微な違いのみです（詳細は DESIGN.md）

## 📋 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック（パスワード表示は等幅フォントスタック）。
- 生成ロジックは DOM に依存しない `js/password-core.js` に分離し、`tests/` の単体テスト（`npm test`、Node 標準のテストランナー）で検証します。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: pasuya-v1）。キャッシュされるのはアプリ本体のファイルのみで、生成したパスワードはキャッシュされません。

### 安全性・プライバシー

- 乱数は `crypto.getRandomValues` のみを使用します。`Math.random` は使用しません。
- 文字の選択には棄却サンプリング（rejection sampling）を用い、剰余による偏りが出ないようにしています。シャッフルも同じ乱数源による Fisher-Yates 法です。
- 生成したパスワードや設定は、サーバーへ送信されません。`localStorage` / `sessionStorage` / Cookie 等への保存も行いません（テーマの選択のみ `localStorage` の `pasuya-theme` キーに保存します）。履歴機能はありません。
- 外部リソース・ライブラリは読み込みません。
